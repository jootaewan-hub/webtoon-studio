# 아트 디렉션

## G6 그림체 — 결정 매트릭스

안을 만들 때 아래 축에서 값을 하나씩 골라 조합한다. 3안은 최소 두 축이 서로 달라야 한다.

| 축 | 선택지 |
|---|---|
| 선 | 굵은 G펜 외곽선 / 가는 펜 선 / 선 없는 면 처리 / 연필·목탄 질감 |
| 채색 | 셀(애니) 1~2단 명암 / 브러시 반실사 / 수채 번짐 / 평면 그래픽 / 실사풍(사진 질감) / 3D 베이스+페인팅 |
| 명암 | 강한 콘트라스트(누아르) / 부드러운 그러데이션 / 거의 없음(평면) |
| 팔레트 | 장르색(누아르=남색·나트륨 주황, 로맨스=분홍·크림, 의학=민트·회백) 중 5~7색 HEX |
| 배경 | 사진 기반 트레이스 / 단순화 평면 / 3D 모델 / 여백 중심 |
| 인물 비율 | 실사 7~8등신 / 웹툰 표준 6.5~7등신 / 데포르메(코믹 컷 한정 2~3등신 병용) |
| 효과선·효과음 | 손글씨 붓 효과음 / 굵은 고딕 효과음 / 효과선 많음·적음 |
| 레터링 폰트 | 대사·내레이션·효과음·손글씨 각 1종 |

장르별 출발점(관습이지 규칙이 아님):
- 블랙코미디·피카레스크: 깔끔한 선 + 셀 채색 + 진지한 연출과 데포르메 리액션의 낙차.
- 스릴러·누아르: 강한 명암, 제한 팔레트, 실루엣 많이.
- 로맨스·성인 드라마: 브러시 반실사, 부드러운 피부 톤, 역광·보케.
- 일상·코믹: 평면 채색, 큰 표정, 데포르메 자주.

**3안 형식** (각 안)
```
안 이름 (한 줄 콘셉트)
- 선 / 채색 / 명암 / 배경 / 비율 / 효과음 스타일
- 팔레트: #… #… #… #… #…
- 폰트: 대사 …, 내레이션 …, 효과음 …, 손글씨 …
- 이 이야기에 맞는 이유: …
- 약점·비용: … (예: 실사풍은 인물 일관성 유지 비용이 큼)
- 맛보기: 같은 인물 얼굴 러프 1장, 팔레트 칩, 효과음 견본
```
- 화풍을 특정 생존 작가 이름·작품명으로 지시하지 않는다. 특징을 말로 쓴다.
- 레퍼런스 이미지는 장르·시대 사진(고증) 위주로 찾는다. 다른 웹툰 컷을 복제 참고로 쓰지 않는다.
- 폰트는 웹툰 상업 사용 라이선스를 확인할 것(무료 폰트도 조건이 다르다). 확인 못 하면 보고에 적는다.

## G7 캐릭터 디자인

`design/characters.json` 형식:
```json
[{"id":"mujin","name":"무진","age":"30대 초반","adult":true,
  "height":"175cm","build":"slim","head_ratio":7,
  "hair":"side","hair_color":"#1C1F26","skin":"#F2D2B6",
  "face":"갸름한 얼굴, 가는 눈, 둥근 금속테 안경",
  "accessories":["glasses"],
  "outfits":[{"label":"수술복","color":"#6DB6A8"},{"label":"수의 4519","color":"#8E9AAA"}],
  "expressions":["무표정","입꼬리만 웃음","당황","분노","식은땀","공허"],
  "acting":"감정은 안경 반사광과 입꼬리로만",
  "variants":[{"label":"A 마른 안경","build":"slim","hair":"side"},{"label":"B 단단한 체격","build":"stocky","hair":"buzz"}]}]
```
- build: `slim`·`average`·`stocky`·`curvy`·`petite`. hair: `side`·`pony`·`buzz`·`spiky`·`slick`·`bald`·`long`·`bob`.
- accessories: `glasses`·`shades`·`cap`(간호사 캡)·`chain`·`earring`·`scar_r`(오른쪽 흉터).
- 첫 번째 의상이 시트에 그려진다. 의상 항목에 `"bottom": "pants"|"skirt"|"long_skirt"`, `"pants": "#HEX"`(바지 색)를 줄 수 있고, 치마일 때 다리 색은 인물의 `legwear`(예: 흰 스타킹 `#F4F4F2`, 없으면 피부색).
- 표정 이름은 자유롭게 쓴다. 스케치는 이름 속 낱말로 얼굴을 고른다: 무표정·냉정 / 입꼬리·비웃 / 웃음·미소 / 발랄·활짝 / 당황·놀람 / 분노 / 식은땀·초조 / 공허·멍 / 슬픔·울먹 / 곁눈·나른 / 단호·진지 / 겁·공포.
- **시안(G7 고르기)**: `variants`를 2개 넣고 `studio.py sketch --variants` → 인물별 A/B 비교 시트로 고르게 한다.
- **확정 후**: 고른 값을 본문에 반영하고 `variants`를 지운 뒤 `studio.py sketch` → 턴어라운드(정면·3/4·측면·뒷모습) + 표정 6종 + 의상 칩.
- 앳돼 보이기 쉬운 성인은 `adult: true`와 나이를 적고, 시트에도 표시된다.
- 이미지 생성 도구로 완성 시트를 만들 때 프롬프트 골격: "character turnaround sheet, front / three-quarter / side / back, neutral pose, plain background, [외형 고정값], [스타일 확정본], fictional adult character, not resembling any real person".

## G8 소품·배경

**소품 고르기**: 원문·대본에서 소품을 뽑아 표로 보여 주고 우선순위를 고르게 한다.
`소품 | 등장 장면 | 이야기 속 역할(복선·상징·개그) | 고증 필요 여부 | 우선순위`

`design/props.json`:
```json
[{"id":"pager","name":"삐삐(무선호출기)","era":"1990년대","material":"검정 플라스틱, 연두 액정",
  "size":"손바닥만 함","colors":["#2B2F3A","#A3C27E"],"role":"0505 암호, 들통의 열쇠",
  "scenes":["2-016","2-109"],"ref":"https://… (고증 사진 페이지)"}]
```
- 소품마다 Claude가 단순 선화 SVG를 직접 그린다: viewBox 0 0 300 300, 외곽선 3px #1C1F26, 평면 채색 2~3색, 정면+측면 두 모습이 필요하면 나란히. `design/props/<id>.svg`.
- `studio.py props` → 카드 시트(그림, 이름, 재질, 크기, 색, 역할, 등장 컷, 고증 링크).

**배경 설정** `design/sets.md`: 장소별 평면 배치도(문·창·가구 위치를 글 또는 간단한 SVG), 시간대별 조명, 대표 색, 반복 등장 소품, 카메라가 자주 놓이는 자리.
