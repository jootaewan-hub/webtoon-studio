# 트랙별 제작 요령

## 공통: 인물 일관성
1. characters.json의 각 인물로 정면·측면·전신 기준 이미지를 먼저 만든다(배경 없음, 같은 조명).
2. 이후 모든 컷 생성 시 해당 인물의 기준 이미지를 참조 이미지로 함께 넣는다.
3. 의상이 바뀌는 장(수술복→수의→가운→턱시도)마다 기준 이미지를 한 장씩 추가한다.

## webtoon_real (실사 웹툰)
- 캔버스 비율은 컷의 width×height를 따른다. 세로가 긴 컷(1100px 이상)은 위아래 여백을 두어 스크롤 리듬을 만든다.
- 생성 이미지에는 글자를 넣지 않는다. 레터링은 프롬프트의 '레터링' 목록으로 후공정(포토샵, Figma, Canva 등)에서 얹는다.
- 결과물은 renders/webtoon_real/<컷번호>.png.

## webtoon_adult (19세 드라마)
- 차이는 수위가 아니라 톤이다: 더 어두운 조명, 피사계 심도 얕게, 밀착 구도, 숨·손·시선 연기.
- intimate 컷은 실루엣·역광·손·반지·소품 컷 분할로 긴장감을 만든다. 노출이나 행위의 직접 묘사는 만들지 않는다.

## shorts (9:16)
- 장별 1편. 예상 길이가 60초를 넘으면(대본에 표시됨) 내레이션만 있는 컷부터 합치거나 뺀다.
- 첫 2초에 그 장에서 가장 강한 대사나 효과음 컷을 미리 보여 주는 훅을 넣는다.
- `python kit.py shorts-script` → `bash outputs/shorts_ffmpeg/short_NN.sh`로 무음 러프컷을 만든다(ffmpeg 필요). 자막·VO·음악은 편집 툴에서 얹는다.

## anim (애니메이션)
- 2D 리미티드 기준: 배경(BG) 고정 + 인물 레이어 + FX 레이어 + 레터링.
- 카메라 표기: slow push-in(클로즈업), snap zoom + shake(집중선 컷), slow tilt down(원경·세로 긴 컷), cut sequence(분할 컷).
- 샷 길이는 대사 글자 수와 컷 높이로 추정한 값이다. 립싱크 녹음 후 실제 길이로 바꾼다.
