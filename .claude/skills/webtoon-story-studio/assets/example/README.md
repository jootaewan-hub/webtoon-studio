# 예시 데이터 (「낙동강을 헤엄쳐 나온 남자」에서 발췌)

studio.py 입력 형식 견본이다. 새 프로젝트에 그대로 복사하지 말고 형식만 참고한다.

- design/characters.json — 외형 고정값, 의상(치마·스타킹 포함), 표정 이름, 시안(variants)
- design/props.json + design/props/*.svg — 소품 고정값과 Claude가 직접 그린 단순 선화
- design/style.json — 확정 스타일(팔레트는 name/hex)
- story/beats.json — 컬러 스크립트 입력
- anim/storyboard_anim.md — 애니메이션 콘티 10열 형식
- decisions.md, notes.md — 결정 로그, 고증 노트
