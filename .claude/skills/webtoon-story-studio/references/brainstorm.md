# 결정 게이트 진행법

## 좋은 안의 조건
- **실제로 다르다.** 세 안이 같은 축의 정도 차이(조금 어둡게/더 어둡게)면 안 된다. 다른 축을 건드린다. 예: 로그라인 3안이면 ① 주인공 시점의 피카레스크 ② 피해자 남편 시점의 복수극 ③ 목격자 인턴 시점의 블랙코미디.
- **작다.** 안 하나는 요지 한 줄 + 근거 2~3줄 + 맛보기 하나. 맛보기는 그 안이 무엇을 만들어 낼지 보여 주는 최소 샘플이다.
- **정직하다.** 안마다 약점을 적는다. 추천은 하나만, 이유와 함께.
- **원문과 리서치에 묶여 있다.** 근거가 원문 표현이나 고증 노트에 있으면 짚는다.

## 맛보기 종류 (게이트별)

| 게이트 | 맛보기 |
|---|---|
| G1 방향 | 로그라인 1문장 + 그 톤으로 쓴 첫 문장 1줄 + 결말 한 줄 |
| G2 인물 | 인물 한 줄 소개 + 그 인물다운 대사 2줄 + 외형 키워드 3개(고른 뒤 심화 바이블·LOCK까지 확정해야 G4로 간다) |
| G3 구성 | 회차별 한 줄 + 각 회의 마지막 훅 한 줄 |
| G4 소설 문체 | 같은 장면(5~8문장)을 문체별로 |
| G5 대본 형식 | 같은 씬의 첫 10줄을 형식별로 |
| G6 그림체 | 팔레트 칩 + 같은 인물 얼굴 러프 스케치 + 말풍선·효과음 글꼴 견본 |
| G7 캐릭터 시안 | 인물별 2안 실루엣·헤어·의상 비교 스케치(`studio.py sketch --variants`) |
| G8 소품 | 소품 목록과 각 소품의 이야기 속 역할, 우선순위 표 |
| G9 콘티 밀도 | 같은 장면을 웹툰 표준(컷 수 n)과 촘촘한 판(컷 수 2n)으로 각각 5~8컷 |
| G10 연출 | 효과음 표기 체계 2안(규칙형/자유형), BGM 체계 2안(모티프 하나+악기 변주 / 인물별 테마), 조명 규칙 |
| G11 애니 콘티 | 같은 웹툰 컷 3개를 샷 분할 2안으로 + 회차 예상 샷 수·길이(분할 칸 수로 추정) |

## 질문 형식

선택지 질문 도구가 있으면:
- 문항 제목(header)은 12자 이내, 질문은 한 문장.
- 선택지는 2~4개, 추천안이 맨 앞이고 라벨 끝에 '(추천)'.
- 미리보기(preview)를 지원하면 맛보기를 미리보기에 넣는다.
- 여러 개를 고를 수 있는 질문(예: 살릴 소품)은 다중 선택으로.
- 사용자는 언제나 '기타'로 직접 쓸 수 있으니, 섞기·수정 요청도 받는다.

도구가 없으면:
```
G1 방향 — 셋 중 하나를 고르거나 섞어 주세요.
1) [추천] 피카레스크: …  (이유 …, 약점 …)
2) …
3) …
```

한 번에 최대 4문항. 문항끼리 서로 의존하면(톤에 따라 결말이 달라짐) 나눠서 묻는다.

## '끝까지 진행' 모드

사용자가 "끝까지 진행해", "추천대로 다 해"라고 하면 그 시점부터 게이트마다 추천안으로 간다.
- 고른 안을 `decisions.md`에 **잠정**으로 적고, 이유 칸에 사용자 말을 인용한다(예: "끝까지 진행해" → 추천안).
- 비교한 안(A·B)과 추천 이유를 산출물 머리에 2~3줄 남긴다. 나중에 사용자가 바꿀 때 무엇과 비교했는지 보이게 한다.
- 검수(별도 에이전트, 자동 검사기)는 건너뛰지 않는다.
- 사용자가 어떤 단계를 멈추게 하면(도구 호출 거절 등) 그 단계를 다시 시도하지 않는다. 더 가벼운 대체 수단을 쓰고, 보고에 '미실시'로 적는다.
- 마지막 보고에 잠정 목록을 모아 보여 준다. 규격과 다르게 처리한 것도 함께 보여 준다(예: 장면 컷 수 초과, 원문 우선으로 지시와 다르게 한 것).

## 사용자가 확정하지 않을 때
- 답이 없거나 "몰라"면 추천안으로 잠정 확정하고, `decisions.md`에 '잠정'으로 적는다. 다음 게이트로 가되, 잠정 항목에 크게 의존하는 대량 작업(소설 전체, 콘티 전체)은 시작 전에 한 번 더 확인한다.
- "다 별로"면 무엇이 별로인지 한 문항으로 묻고(톤? 인물? 결말?), 그 축만 바꾼 새 안을 낸다.

## decisions.md 형식

```
| 게이트 | 결정 | 고른 안 | 이유(사용자 말 그대로 있으면 인용) | 상태 | 날짜 |
|---|---|---|---|---|---|
| G1 | 장르·톤 | 1안 피카레스크 블랙코미디 | "주인공은 악인으로" | 확정 | 2026-10-07 |
| G6 | 그림체 | 2안 굵은 선 셀 2단 | 추천대로 | 잠정 | 2026-10-07 |
```

이 파일이 프로젝트의 기준이다. 뒤 단계 산출물이 이 파일과 어긋나면 산출물을 고친다.

## 진행 상태 알리기
게이트가 끝날 때마다 한 줄: "G2 인물 확정. 다음은 G3 구성: 단편 1화와 3화 구성 중 고르실 차례입니다." 작업 목록 위젯이 있으면 게이트를 작업 항목으로 두고 확정 때마다 완료 처리한다.
