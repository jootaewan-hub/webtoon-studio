# 연출 노트

연출 노트는 작품 전체 원칙 + 장면별 포인트 두 부분으로 쓴다. G10에서 아래 항목마다 2안을 내고 고르게 한다(전부 묻지 말고, 이 작품에서 갈리는 것만).

## 1. 세로 스크롤 템포
- 컷 높이가 시간이다. 짧은 컷(360~600px) 연속 = 빠름, 긴 컷(1200px+) = 멈춤·압도.
- 컷 사이 여백: 기본 40px, 장면 전환 120px, 반전 직전 240px 이상(독자가 손가락을 한 번 더 움직이게).
- 한 화면(모바일 약 1.5컷)에 정보 하나.
- 회차 첫 화면: 장소·시간·인물이 한 번에. 마지막 화면: 훅.

## 2. 앵글과 샷이 뜻하는 것
| 선택 | 효과 |
|---|---|
| 로우앵글 | 위압, 권위(회진하는 레지던트, 판사) |
| 하이앵글·부감 | 작아짐, 감시당함, 상황 전체 |
| POV | 독자를 공범으로(문틈, 커튼 뒤) |
| 오버숄더 | 대화의 힘 관계(누구 어깨 너머인가) |
| ECU 인서트 | 정보 강조, 시간 늘이기(반지, 삐삐 액정) |
| 무음 2인 숏 | 어색함, 웃음 타이밍 |

## 3. 조명·색과 감정
- 장면마다 광원 하나를 정한다(형광등, 비상구 초록, 가로등 나트륨, 해운대 역광).
- 색 규칙은 컬러 스크립트와 맞춘다. 감정이 바뀌는 지점에서만 색을 바꾼다.
- 성인 장면은 단일 광원·낮은 채도·실루엣으로 수위와 분위기를 같이 잡는다.

## 4. 효과음(SFX) 연출

**웹툰 레터링 규칙** (G10에서 2안 제시)
| 항목 | 정할 것 |
|---|---|
| 글꼴 | 타격·폭발=굵은 붓/고딕, 작은 소리=가는 손글씨, 기계음=모노 계열 |
| 크기 | 소리 크기에 비례. 최대 효과음은 컷 폭의 60% 이하(그림을 덮지 않게) |
| 색 | 기본 잉크색, 강조만 적색. 밤 장면은 흰 글자+어두운 테두리 |
| 배치 | 소리 나는 물체 근처, 움직임 방향으로 기울임. 말풍선과 겹치지 않음 |
| 반복 | 리듬은 반복 수로(끼익… 끼익…), 점점 작게 = 멀어짐 |
| 무음 | 결정적 순간은 효과음을 빼고 여백으로(반전 직전, 충격 직후) |

**한국어 의성어·의태어 사전 만들기**: 작품에서 쓰는 효과음을 `story/sfx_list.md`에 모은다.
`효과음 | 뜻·소리 | 장면 | 글꼴·크기 | 애니/쇼츠 사운드 큐`
예: `퍽! | 둔탁한 타격 | 3장 망치 | 붓 대형 적색 | 둔탁한 타격 폴리 + 0.3초 무음`
- 의태어(반짝, 쭈뼛)도 같이 관리한다. 같은 소리는 작품 내내 같은 표기로.

**영상(쇼츠·애니) 사운드 큐**: 효과음 레터링을 사운드로 옮길 때 폴리(발소리, 문), 앰비언스(병동 웅성임, 강물), 음악 스팅어(반전), 무음 구간을 정한다. 애니 콘티(G11)의 SFX·BGM 칸이 이 목록을 쓴다.

## 5. 말풍선
- 읽는 순서는 위→아래, 좌→우. 꼬리는 화자 입 쪽.
- 대사 풍선 한 컷 최대 2개. 길면 컷을 나눈다.
- 종류: 일반(둥근), 외침(각진+그림자), 생각(점선), 속삭임(얇은 점선+작은 글씨), 전화·화면 밖(꼬리 번개형 또는 사각), 내레이션(사각 박스, 낮·밤 색 구분).
- 사투리는 표기 그대로. 읽기 어려운 사투리는 대사 길이를 줄인다.

## 6. 웃음과 반전 타이밍 (블랙코미디)
진지한 컷 → 무음 리액션 컷 → 반전 대사(짧게) → 여백. 웃음 포인트는 설명하지 않는다.

## 7. 장면별 연출 포인트 형식
```
### S#7 옥상 목격
- 목표 감정: 숨 막힘 → 무력감
- 템포: 짧은 컷 5개(계단·문틈·눈) → 긴 POV 컷 1개 → 무음 3컷
- 앵글: 정만 POV, 철문 틈 검은 테두리 프레임 유지
- 조명·색: 해운대 역광, 인물 실루엣, 채도 낮춤
- 효과음: 작은 숨소리 손글씨, 마지막은 무음
- 수위 처리: 실루엣·소품·입술 ECU까지
```

## 8. 매체를 옮길 때
- 쇼츠: 첫 2초 훅, 컷당 1.5~3초, 자막 크게, 효과음은 사운드로 바꾸고 화면 글자는 줄인다.
- 애니: 웹툰 한 컷 = 샷 1~4개. 카메라 무빙과 연기 시간이 생기므로 대사 사이 '숨'을 설계한다(anim_storyboard.md).

## 9. G10 진행 순서 (실제 작품에서 쓴 절차)

연출 노트 `story/direction.md`는 1부(작품 전체 원칙)와 2부(장면별 포인트)로 쓴다.

**1부에서 정할 것** (갈리는 것만 2안을 내고, 나머지는 콘티에서 읽어 쓴다)

1. **이 작품의 연출 문법 2~3개.** 작품 고유의 반복 장치를 화면 규칙으로 바꾼다.
   - 예: "같은 문장, 같은 구도, 다른 색". 반복 대사는 같은 카메라로 그리고, 바뀌는 것은 인물 대표 색뿐이다.
   - 예: "부감은 포위, 클로즈업은 단서", "웃음은 무음 한 박자 뒤".
2. **세로 스크롤 템포**: 컷 높이 구간, 컷 사이 여백 기준(기본 40px, 전환 120px, 반전 240px, 회차 끝 360px).
3. **앵글이 이 작품에서 뜻하는 것**: 표로 정리하고, 대표 컷 번호는 실제 콘티 데이터에서 확인해 적는다(추측 금지).
4. **조명·색**: 장소별 기본 광원, 회상 톤, 대표 색 규칙, 색이 바뀌는 지점.
5. **효과음 표기 체계(2안)**: A 규칙형(크기 4단계·색의 뜻 고정·같은 소리 같은 표기) / B 자유형. 인계 대상이 생성기·Codex면 A를 추천한다.
6. **말풍선 종류표**: 대사·외침·생각·속삭임·전화·V.O.·방송·메시지·내레이션, 동시 대사.
7. **수위 연출 원칙**: 관능의 문법, 움직이는 매체에서 더 보수적으로, 아이 장면, 폭력.
8. **BGM 체계(2안)**: A 모티프 하나 + 인물별 악기 변주 / B 인물별 테마. 반복 장치가 있는 작품은 A가 소리로도 겹쳐져 유리하다. 큐 이름(M1~)과 무음 구간, 장소별 앰비언스 표를 함께 정한다.
9. **매체 전환**(쇼츠·애니).

**2부**: `python3 tools/direction_scenes.py`가 콘티 데이터에서 장면마다 뽑는다. 콘티를 고치면 kit.py import 뒤에 다시 돌린다.
- 컷 범위, 템포 띠(▪◼█), 샷·앵글 분포
- 조명, 트랙, 효과음·무음 컷
- 수위 처리, 아이 장면

**효과음 사전과 표기 통일** (`story/sfx_list.md`)
1. `python3 tools/sfx_tools.py extract`로 콘티의 효과음 전부를 뽑는다(표기·컷·크기·글꼴). 결과는 `research/sfx_raw.json`이다.
2. 서브에이전트가 사전을 쓰고 표기 통일 목록을 JSON으로 낸다.
   - 사전은 소리 원천별로 분류하고, 열은 `효과음 | 뜻·소리 | 장면 | 글꼴·크기 | 애니/쇼츠 사운드 큐`다.
   - 통일 기준 우선순위: 원작 표기 > 배경 설정서(장소별 '소리') 표기 > 최다 표기.
   - 원천이 다르면 표기가 비슷해도 바꾸지 않는다. 반복 리듬(쿵… 쿵…)은 연출이므로 유지한다.
3. `python3 tools/sfx_tools.py apply <통일.json>`으로 웹툰 콘티와 애니 콘티에 함께 반영한다. 그다음 kit import → direction_scenes → anim merge·cues를 다시 돌린다.
