# 이미지 생성 도구 선택과 거절·변경 대응

그림은 외부 도구(ChatGPT, Codex, 기타 생성기, 사람 작가)가 만든다. 이 문서는 컷마다 어떤 도구로 보낼지 정하는 법과, 생성기가 콘티와 다르게 그렸을 때 어떻게 할지를 다룬다.

## 원칙

- **생성기 정책을 피해 가는 프롬프트는 만들지 않는다.** 금지어를 돌려 말하기, 정책 문구 무력화 지시, 단계를 쪼개 몰래 조립하기 같은 방법을 쓰지 않는다.
  - 사용자가 요청하면 한 줄로 거절하고, 아래의 '도구 경로 나누기'를 제안한다.
  - 그렇게 만든 결과물은 계정 제재로 한꺼번에 쓸 수 없게 될 수 있다.
- 성인 컷은 **그 콘텐츠를 이용약관상 허용하는 도구나 사람 작가**에게 보낸다.
  - 도구를 바꿔도 작품의 선은 그대로다.
  - 성기·유두 노출, 성행위의 직접 묘사, 체액, 미성년으로 보이는 표현, 실존 인물 닮음은 어느 도구에서도 만들지 않는다.
- 생성기가 말없이 바꾼 그림은 **콘티와 대조해 걸러 낸다.** 바뀐 것을 기록하고, 다시 만들지 다른 경로로 보낼지 사람이 정한다.

## 도구 경로(route) 나누기

`tools/build_handoff.py`가 컷마다 경로를 붙인다. 결과는 `handoff/prompts/*.jsonl`의 `route`와 매니페스트에 들어간다.

| 경로 | 대상 컷 | 도구 |
|---|---|---|
| A | 대부분의 컷: 일상, 대화, 코미디, 소품 인서트, 손·입술·실루엣으로 처리한 관능 컷 | 범용 생성기(예: ChatGPT 이미지 생성) |
| B | 관능 태그 컷 가운데 화면 칸에 노출·탈의 단서가 있는 컷: 시트로 가린 나신, 속옷·슬립, 벗겨지는 옷, 드러난 골반·등 | 성인 콘텐츠를 약관상 허용하는 도구, 또는 사람 작가 |

- **B 판정 단서**: `storyboard/data/flags.json`의 `route_b_keywords`. 없으면 `intimate.strong`을 쓴다. 작품마다 조정한다.
  - 키스나 맨어깨 정도는 A로 두는 것이 보통이다.
- **B 도구는 사용자가 고른다.** 후보와 약관은 바뀌므로 고를 때 아래 '도구 현황'을 다시 확인한다.
- **레퍼런스는 같은 것을 쓴다.** A와 B가 같은 확정 레퍼런스(refs/)와 같은 LOCK 문단을 써야 얼굴과 장소가 맞는다. B 도구가 레퍼런스 이미지를 못 받으면, 그 도구용 캐릭터 일관성 수단(예: 학습형 캐릭터 모델)을 따로 준비한다. 이 비용을 사용자에게 미리 알린다.

## 생성기가 콘티와 다르게 그렸을 때

1. **변경 보고를 요구한다.** ChatGPT 프로젝트 지침에 다음 문장을 넣는다.
   - "프롬프트의 어떤 요소를 그대로 그릴 수 없으면 임의로 바꾸지 말고, 생성 전에 무엇을 왜 못 그리는지 말한다. 그린 뒤에는 바뀐 요소(구도·노출·의상·인물 수·소품)를 목록으로 보고한다."
2. **검수한다.** 결과를 콘티 컷과 대조한다.
   - 대조 항목: 샷 크기, 인물 위치, 의상 HEX, 소품, 조명 방향, 노출 범위.
   - 다르면 매니페스트 `notes`에 `changed:노출축소,구도` 식으로 적고 `rejected` 또는 `approved(변경)`로 둔다.
3. **다음 처리를 고른다.**
   - 노출이 줄었지만 장면이 성립하면 가림 장치판으로 확정한다. 가림 장치는 시트·커튼·와인잔·셔츠 자락 → 실루엣 → 손·입술·사물 인서트 순서로 쓴다.
   - 원작의 노출 범위(작품이 허용한 부분 노출)가 꼭 필요하면 그 컷을 경로 B로 옮긴다.
   - 구도나 인물이 바뀐 것은 노출과 상관없는 일관성 문제다. 레퍼런스 이미지를 다시 첨부하고, 한 대화에 한 장면만 다루며, 같은 장면의 앞 컷 결과를 함께 첨부해 재생성한다.
4. **노출을 더 줄인 문장으로 피해 가지 않는다.** 원작 대비 손실은 사용자에게 보고하고, 경로 B로 보낼지 사용자가 정한다.
