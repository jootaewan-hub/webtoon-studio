# 접수

## 원문에서 먼저 뽑을 것
- 사건의 뼈대: 누가, 무엇을, 왜, 어떻게 끝났나 (5줄 이내)
- 원문에 있는 사실 주장 목록 (리서치 대상)
- 원문의 말투·사투리·인상적인 대사 (그대로 살릴 후보)
- 원문이 대화체(단톡방·인터뷰)면 화자가 누구인지, 전언인지 직접 경험인지

## 물어볼 것 (정해지지 않은 것만, 한 번에 최대 4문항)

| 항목 | 선택지 | 묻지 않을 때 기본값 |
|---|---|---|
| 각색 수준 | 완전 허구화 / 뼈대 유지·디테일 변경 / 최대한 그대로 | 실화면 '뼈대 유지', 창작이면 해당 없음 |
| 장르·톤 | 블랙코미디·피카레스크 / 스릴러 / 로맨스 / 휴먼드라마 / 코믹 일상 | 원문 정서에 가장 가까운 것 |
| 이용 등급 | 전체 / 15세 / 19세 드라마 | 15세 |
| 분량 | 단편 1화(60~80컷) / 3화 / 시즌(10화+) | 단편 1화 |
| 산출물 범위 | 전부 / 일부(예: 그림체만, 대본만) | 전부 |
| 그림체 | 사용자가 정함 / 3안 제안 | 3안 제안 |

질문은 선택지형으로 짧게. 사용자가 이미 대화에서 답한 것은 다시 묻지 않는다.

## 실화·실존 인물
- 이름·소속 기관·지역의 세부(병원명, 학교명)는 가명으로 바꾼다. 도시·강 같은 넓은 배경은 유지해도 된다.
- 피해자·관련자가 작품을 보고 자기 이야기임을 알아볼 수 있는지 판단해, 높으면 사용자에게 한 줄로 알린다.
- 원문이 전언(단톡방, 소문)이면 사실 여부를 확인하지 않았다는 점을 결과 보고에 적는다.
- 실존 인물을 조롱하는 농담(정치인·고인 등)은 원문에 있어도 작품에 넣지 않고, 뺐다고 알린다.
- 작품 첫 장이나 끝에 허구 고지문을 넣는다.

## 첫 산출물 머리에 남길 한 줄
"기본값: 각색 수준=뼈대 유지, 등급=15세, 분량=단편 1화, 그림체=3안 제안" 처럼, 사용자가 고르지 않은 값을 적는다.
