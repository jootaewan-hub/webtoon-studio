1. `decisions.md`의 확정 사항
2. `story/bible.md`의 **0-2. 확정 외형(시안 B)**: 작화의 최우선 기준
3. `characters/*.md`의 CHARACTER LOCK, `sets.md`의 SET LOCK, `props.md`의 PROP LOCK

## 3. 작업 순서

**1단계: 레퍼런스 만들기.** `refs/`에 저장하고 `asset_manifest.csv`의 해당 줄을 `approved`로 바꾼다.

1. **인물 7명.** 인물마다 턴어라운드 → 표정 8종 → 의상 시트 → 손·소품 클로즈업 → 키 비주얼 순서로 만든다.
   - 도겸, 유진, 미란: 이미 만든 시안 B 이미지(`characters/_g7_generation_log.md`)를 먼저 업로드하고 시작한다.
   - 세라, 하린, 혜숙, 순옥: 턴어라운드부터 새로 만들고, 사람이 승인하면 확정한다.
2. **소품 10종** 설정화(`props.md`)를 만든다.
3. **장소 13곳**의 빈 배경을 만든다(`sets.md`). 회차·시각별 조명표(N-3)마다 1장씩이다.

**2단계: 컷 이미지 571장.**

1. `prompts/ep<N>_prompts.md`에서 컷 상자를 그대로 복사한다.
2. 상자 아래 '레퍼런스'에 적힌 확정 이미지를 첨부하고 생성한다.
3. 결과는 `renders/ep<N>/<컷번호>_v<N>.png`로 저장하고 매니페스트를 갱신한다.
4. 회차 순서대로, 한 장면 안의 컷을 연달아 생성하면 조명과 의상이 잘 유지된다.

**3단계: 레터링과 조립(Codex, `AGENTS.md`).**

1. `storyboard/cuts.json`의 `lines`로 말풍선·내레이션·효과음을 얹는다. 위치는 화면 칸의 지시를 따른다.
2. 회차별 세로 스크롤 파일을 조립한다. 폭은 800px이다.
   - 컷 사이 여백은 기본 40px, 장면 전환 120px, 반전 직전 240px, 회차 끝 360px이다(direction.md 2절).
3. 쇼츠(9:16)와 애니는 각각 `storyboard/`의 킷 쇼츠 트랙과 `anim/storyboard_anim.md`를 쓴다. 쇼츠 킷은 원본 저장소의 `five-doors/storyboard/outputs/shorts`에 있다.

## 4. ChatGPT에서 일관성을 지키는 법

**도구 경로.** 컷마다 경로가 붙어 있다(`prompts/` 각 컷 제목, jsonl의 `route`).
- **A(505컷)**: ChatGPT로 그린다.
- **B(66컷)**: 원작의 부분 노출·탈의가 화면의 중심인 컷이다. 1화 21, 2화 10, 3화 5, 4화 13, 5화 14, 6화 3.
  - ChatGPT 이미지 생성은 성적 노출을 허용하지 않는다. 성인 모드도 2026년 3월 무기한 연기됐다(`IMAGE_TOOLS.md`). 그래서 B 컷은 ChatGPT가 노출을 줄이거나 구도를 바꾸는 것이 정상 동작이다.
  - B 컷은 성인 콘텐츠를 약관상 허용하는 도구나 사람 작가에게 보내거나, 가림 장치판으로 확정한다.
  - 어느 쪽이든 성기·유두·행위 직접 묘사·체액은 그리지 않는다.
- **생성기 정책을 피해 가는 프롬프트는 쓰지 않는다.**

**변경 보고.** ChatGPT가 콘티와 다르게 그리면 그대로 쓰지 않는다.
- 지침 8번대로 바뀐 요소를 보고받는다.
- 매니페스트 `notes`에 `changed:…`로 적는다.
- 다시 만들지, 경로 B로 옮길지 사람이 정한다.

- ChatGPT 프로젝트 하나를 만들고 `CHATGPT_PROJECT_INSTRUCTIONS.md`의 지침을 붙인다. 파일은 그 문서의 '올릴 파일' 순서대로 올린다.
- **한 대화에서는 한 장면만** 다룬다. 확정한 레퍼런스는 매 요청마다 다시 첨부한다.
- LOCK 문단은 고치지 않는다.
  - 바꾸고 싶으면 `story/bible.md`를 먼저 고치고, 그다음 LOCK을 고친다.
  - 프롬프트는 원본 저장소에서 다시 만든다(`python3 five-doors/tools/build_handoff.py`).
- 생성이 거절되면 노출을 더 줄이지 말고 **가림 장치로 바꾼다.** 순서는 시트·커튼·와인잔·셔츠 자락 → 실루엣 → 손·입술·사물 인서트다(`style_lock.md` 수위 규칙).
- 이미지 안에 글자를 넣지 않는다. 컷 프롬프트에서도 말풍선·효과음 지시는 이미 뺐다.

## 6. 아직 정해지지 않은 것, 확인하지 못한 것

- **기준 이미지가 없다.** 세라, 하린, 혜숙, 순옥은 시안 B 방향만 확정했고, 이미지는 아직 만들지 않았다. 소품과 장소의 기준 이미지도 전부 없다.
- **잠정 결정.** G10 효과음 표기 체계·BGM 체계와 G11 애니 밀도는 사용자 지시("끝까지 진행")에 따라 추천안을 잠정으로 채택했다. 내역은 `decisions.md`에 있다.
  - 애니는 분할 칸을 칸마다 샷으로 나눠 988샷이 됐다. 줄이려면 같은 구도의 분할 칸을 한 샷으로 합치면 된다.
- **ChatGPT 정책.** 2026-10-08 확인 기준, ChatGPT는 성적 노출 이미지를 허용하지 않는다(`IMAGE_TOOLS.md`의 출처). 정책은 바뀔 수 있으니 쓰기 전에 다시 확인한다.
- **경로 B 도구는 미정.** 경로 B를 맡을 도구나 작가는 아직 정하지 않았다(사용자 결정 사항).
- **파일 수 제한 미확인.** ChatGPT 프로젝트에 올릴 수 있는 파일 수는 요금제마다 다르고, 이번에 확인하지 못했다. 그래서 '올릴 파일'에 우선순위를 매겨 두었다.
- **폰트 라이선스 미확인.** 레터링 폰트는 SIL OFL 계열로 알고 있지만, 배포 전에 폰트마다 확인한다.
