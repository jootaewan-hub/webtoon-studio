## 2. 기준 우선순위

1. `decisions.md`의 확정 사항
2. `story/bible.md`의 **0-2. 확정 외형(시안 B)**: 작화의 최우선 기준
3. `characters/*.md`의 CHARACTER LOCK, `sets.md`의 SET LOCK, `props.md`의 PROP LOCK

5. `story/novel.md`과 `story/script.md`: 장면 사실의 기준. 그림이 소설과 다르면 그림을 고친다.

## 3. 작업 순서

**1단계: 레퍼런스(지금 할 수 있음).** 확정된 레퍼런스는 `refs/`에 저장하고 `asset_manifest.csv`에 적는다.

1. 인물 7명을 한 명씩 만든다. 인물마다 턴어라운드 → 표정 8종 → 의상 시트 → 손·소품 클로즈업 → 키 비주얼 순서로 간다.
   - 도겸, 유진, 미란은 이미 만든 시안 B 이미지(링크는 `_g7_generation_log.md`)를 먼저 업로드하고 시작한다.
   - 세라, 하린, 혜숙, 순옥은 턴어라운드부터 새로 만든다. 사람이 승인하면 확정한다.
2. 소품 10종 설정화를 만든다(`props.md`).
3. 장소 13곳 빈 배경 설정화를 만든다(`sets.md`). 장소마다 주 조명 시간대 2장씩이다.

**2단계: 콘티와 컷 이미지(다음 단계에서 이 폴더에 추가 예정).**

- 웹툰 콘티(G9): 6화, 화당 약 60컷. 컷마다 크기, 샷, 화면, 대사, 효과음이 들어간다.
- 컷별 이미지 프롬프트: 컷 지시 + 등장인물 LOCK + 장소 SET LOCK + 트랙 문구를 자동으로 조립한다.
- 연출 노트(G10)와 애니메이션 콘티(G11).
- 콘티가 오면 Codex가 `AGENTS.md`의 '컷 단계' 절차를 따른다.

**3단계: 레터링과 조립(Codex).** 대사, 효과음, 내레이션을 이미지 위에 얹고, 세로 스크롤 회차 파일과 쇼츠용 9:16 컷을 만든다.

## 4. ChatGPT에서 일관성을 지키는 법

- 프로젝트 하나를 만들고 `CHATGPT_PROJECT_INSTRUCTIONS.md`를 '지침'에 붙인다. `style_lock.md`, `characters/`, `props.md`, `sets.md`를 프로젝트 파일로 올린다.
- **한 대화에서는 한 인물만** 다룬다. 확정한 이미지는 다음 요청 때 다시 첨부한다.
- 프롬프트의 LOCK 문단은 고치지 않는다. 바꾸고 싶으면 `story/bible.md`를 먼저 고치고, 그다음 LOCK을 고친다.
- 거절되면 노출을 줄이지 말고 **가림 장치로 바꾼다**. 시트, 커튼, 실루엣, 손 인서트를 쓴다(`style_lock.md` 수위 규칙).
- 이미지 안에 글자를 넣지 않는다(`no text`). 글자는 레터링 단계에서 넣는다.

## 5. 검수 체크리스트 (이미지 한 장마다)

- [ ] 인물의 얼굴, 머리 색·길이, 체형이 LOCK과 일치하는가. 0-2 시안 B 기준이다.
- [ ] 고유 표식이 있는가.
  - 도겸: 왼손 화상 흉터와 시계, 이마에 흘러내린 머리 한 가닥
  - 유진: 웃지 않는 눈
  - 세라: 비너스 보조개
  - 하린: 금테 타원 안경
  - 혜숙: 진주 44알
- [ ] 장면의 날짜·시각에 맞는 조명인가(`sets.md`의 조명표).
- [ ] 다섯 여자가 함께 나오면 각자의 대표 색이 컷 안에 있는가.
- [ ] 수위: 성기·행위 직접 묘사가 없는가. 아이가 관능 장면과 같은 공간에 없는가. 하린이 성인으로 보이는가.
- [ ] 실제 브랜드 로고나 실제 화폐 도안을 그대로 그리지 않았는가.
- [ ] 이미지 안에 글자가 없는가.
