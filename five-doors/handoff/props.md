# 소품 사양서와 프롬프트 (PROP LOCK) — 「단톡방에 그 남자가 있다」

각 소품의 고정값과 이미지 생성 프롬프트를 정리했다.
- 근거는 소설·대본과 `story/bible.md`이다. `*`는 새로 정한 세부다.
- 모든 프롬프트는 `style_lock.md`의 트랙 1 문구로 시작한다.
- 소품 설정화는 흰 배경에 놓고, 정면·측면·디테일 세 컷을 한 장에 그린다.

공통 시작 문구(소품 설정화):
```text
Prop design sheet for a Korean adult webtoon, semi-realistic glossy digital painting, soft studio lighting, plain off-white background, front view + side view + detail close-up on one sheet, no text, no logos, no people unless specified.
```
