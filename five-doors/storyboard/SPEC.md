# 웹툰 콘티 작성 규격 — 「단톡방에 그 남자가 있다」 (세분화판)

## 읽을 것 (담당 회차는 처음부터 끝까지 반드시)
- `story/novel.md`: 원작 소설. 대사와 내레이션의 원문 기준이다.
- `story/script.md`: 대본. 씬 번호 S#, 샷 단위 지문, 회차 끝 '변경 기록'.
- `story/bible.md`: 인물. **0-2 확정 외형(시안 B)이 작화 기준**이다. 4절 회차별 의상, 5절 몸짓, 3-1 다섯 여자 대비표도 본다.
- `handoff/sets.md`: 장소. 평면 배치, 회차·시각별 조명, 카메라 자리, 수위 장치.
- `handoff/props.md`: 소품 고정값.
- `handoff/style_lock.md`: 트랙 1·2·3, 레터링 폰트, 수위 규칙.
- `/home/claude/webtoon-adaptation-kit/references/storyboard_spec.md`: 킷 형식의 원본 규격. 아래와 다르면 **이 문서가 우선**이다.

## 목표
웹소설에 삽화를 붙인 느낌이 나지 않게, 실제 웹툰처럼 동작·감정·시선 단위로 쪼갠다.
- 분량: **회차당 75~95컷.** 원작 문단 1개당 3~6컷, 관능·반전 장면은 더 촘촘히.
- 대본의 씬(S#) 하나는 4~10컷이 된다.

## 컷 쪼개기 원칙
1. 한 컷에는 한 동작, 한 감정, 한 정보 중 하나만 담는다.
   - 대사는 컷당 최대 2개다.
   - 화자가 다르면 원칙적으로 컷을 나눈다.
2. 장면 문법:
   - 설정샷(어디·언제) → 인물 등장 → 대사 교차(숏/리버스숏)
   - → 무음 리액션 CU → 디테일 인서트(ECU) → 여운·전환 컷
3. 무음 컷을 적극적으로 쓴다(눈 깜빡임, 침 삼킴, 손 멈춤, 시선 이동, 침묵의 2인 숏).
4. 세로 스크롤 리듬:
   - 짧은 컷(360~600) 3~5개로 긴장을 쌓은 뒤 긴 컷(1200~1800)으로 터뜨린다.
   - 가로 2~3분할 컷도 섞는다.
   - 회차 마지막 컷은 훅이다.
5. 블랙코미디 타이밍은 "진지한 컷 → 한 박자 무음 리액션 → 반전 대사"다.
6. **원작 대사·내레이션은 빠짐없이 원문 그대로** 쓴다.
   - 새로 넣을 수 있는 것은 짧은 리액션("…", "네?", 숨소리)뿐이다.
   - 새 사건이나 설정은 넣지 않는다.
   - "○○가 말했다" 같은 화자 지시문은 말풍선이 대신하므로 내레이션으로 옮기지 않는다.
7. 화면 설명은 구체적으로 쓴다.
   - 자세, 손 위치, 표정(눈썹·입·시선), 의상(색·재질·몸 라인), 배경 소품, 조명(광원·방향·색), 효과선.
   - "분위기 있게" 같은 추상어는 쓰지 않는다.

## 출력 형식 (엄격, 킷이 자동으로 읽는다)
- 회차 제목: `### 1화. 너한테만 하는 얘긴데`
- 장면 소제목: `#### 장면: S#3 유진의 밤 (101동 3801호 침실, 9월 1일 화 밤 10:30)`. 대본의 S# 번호를 반드시 단다.
- 장면 소제목 바로 아래 한 줄 `연출 메모: …`에 아래 다섯 가지를 쓴다.
  - 장소 ID(sets.md 번호)
  - 조명(sets.md의 해당 시각 줄을 요약)
  - 인물별 의상(bible 4절 회차별 의상, 색 HEX)
  - 트랙
  - 이 장면의 감정 목표
- 표 헤더는 정확히 아래 5열이다.

| 컷 | 크기 | 샷·앵글·인물 | 화면·연출 | 대사·내레이션·SFX |
|---|---|---|---|---|

- **컷**: `회차-세자리` (예: `1-001`), 회차마다 001부터 시작한다. 1화 앞에 표지가 있으면 `0-001`. 에필로그(6화 출소, 모델하우스)는 6화 번호를 이어서 쓴다.
- **크기**: `800×높이`(360~1800, 40 단위). 분할 컷이면 화면·연출 칸에 "가로 2분할"이라고 쓴다.
- **샷·앵글·인물**: `샷 · 앵글 · 인물(위치)`
  - 샷: ECU / CU / BS / MS / FS / LS / ELS / INS / TXT
  - 앵글: 아이레벨 / 로우 / 하이 / 부감 / 앙각 / POV(누구 시점) / 측면 / 뒷모습 / 오버숄더(누구 너머)
  - 인물 이름은 **도겸, 유진, 미란, 세라, 하린, 혜숙, 순옥**으로 쓴다. 단역은 역할명(고미숙, 남정애, 백지연, 미란 어머니, 지호, 소이, 형사, 재판장, 상담 직원 등).
  - 위치는 좌·중·우·전경·후경, 실루엣이면 `(실루엣)`, 인물이 없으면 `인물 없음`.
- **화면·연출**: 2~4문장.
  - 트랙 2(코미디 셀)나 트랙 3(실루엣 티저) 컷은 맨 앞에 `[트랙2]` 또는 `[트랙3]`을 붙인다. 표시가 없으면 트랙 1이다.
  - 말풍선 위치(좌상, 우하 등)도 적는다.
- **대사·내레이션·SFX**: ` / `로 구분한다.
  - 형식은 `화자: 내용`.
  - 내레이션은 `내레이션:`, 문자·카톡은 `문자(도겸→미란):`, 생각은 `유진(생각):`, 속삭임은 `미란(속삭임):`, 전화 너머는 `도겸(전화):`.
  - 효과음은 `SFX:` 또는 `SFX(작게/대형/적색):`. 대사가 없으면 `(무음)`.
- 표 칸 안에 `|` 문자를 쓰지 않는다. 한 행은 한 줄이다.

## 수위 규칙 (이 작품 기준: 낙동강보다 과감하게, 선은 지킨다)
- **허용**
  - 몸에 붙는 의상과 몸 라인 강조(가슴 굴곡, 잘록한 허리, 골반·허벅지 라인).
  - 깊은 V넥, 슬릿, 크롭.
  - 슬립·속옷 차림, 옷이 벗겨지는 과정(끈이 어깨에서 미끄러짐, 단추, 지퍼).
  - 드러난 등·어깨·쇄골·허리·허벅지, 시트로 가린 나신.
  - 실루엣과 역광의 맞닿은 몸, 체중이 실리는 자세, 손과 입술의 위치, 땀과 숨, 흐트러진 머리, 떨어진 옷가지.
  - 정사 장면 하나는 8~16컷으로 충분히 쓴다.
- **그리지 않는 것**
  - 성기, 유두 노출, 삽입·행위의 직접 묘사, 체액.
  - 이 지점에서는 sets.md의 수위 장치(커튼, 시트, 실루엣 광원, 사물 인서트)로 컷을 넘긴다.
- **아이들**: 지호와 소이는 관능 장면과 같은 컷·장면·공간에 두지 않는다.
- **성인 표현**: 하린(25)은 성인 체형과 표정으로 그린다.
- **폭력**: 없다. 체포 장면도 비폭력이다.
- **실제 브랜드·화폐**: 실제 브랜드 로고와 실제 화폐 도안은 그리지 않는다.

## 레터링 표기 (style_lock.md)
- 효과음은 화면·연출 칸에 '붓 효과음(East Sea Dokdo)' 또는 '코미디 고딕(Black Han Sans)'으로 적는다.
- 크기와 색은 SFX 괄호에 적는다.
- 결정적 순간(반전 직전, 충격 직후)은 효과음을 빼고 여백으로 둔다.
