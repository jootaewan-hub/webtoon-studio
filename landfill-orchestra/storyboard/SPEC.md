# G9 웹툰 콘티 규격서 — 「깡통 바이올린」

이 문서는 킷 기본 규격(`skills/webtoon-adaptation-kit/references/storyboard_spec.md`)보다 우선한다. 단, '넘지 않는 선'(아래 7절)은 어떤 경우에도 완화하지 않는다. 기준 우선순위는 `decisions.md` > `story/bible.md`·`design/style_guide.md` > `story/script.md` > `story/novel.md`.

## 1. 입력

| 파일 | 쓰는 법 |
|---|---|
| `story/script.md` | **콘티의 정본.** 대사·내레이션·효과음·카메라 의도·연기 메모가 다 있다. 대사는 소설 대사를 글자 그대로 옮긴 것이다(누락 0). |
| `story/novel.md`(= `storyboard/source/novel.md`) | 장면의 감정과 디테일을 확인하는 참고 |
| `storyboard/source/scene_index.md` | 씬(화-S#)마다 빛·인물 의상·배경 id와 카메라 자리·소품 키·소리 색 순간 |
| `design/style_guide.md` | 1절 그림 규칙, 2절 소리 색 규칙, 4절 카메라 문구, 6절 인물 고정 문구(단역 포함), 7절 넘지 않는 선 |
| `design/scene_presets.md` | 씬별 빛·색·의상 상세 |
| `story/continuity.md` | 이름·장소·악기·시간·복선의 기준 |
| `story/script_cut_candidates.md` | 축소 후보. **모두 적용한다**(대사는 모두 남기는 안이다) |
| `storyboard/samples/density_S1.md` | B안 표본(1화 S#1, 12컷). 형식과 밀도의 기준 |

## 2. 밀도 (G9 결정: B안 리듬, 사용자 확정 2026-10-10)

| 화 | 목표 컷 수 | 비고 |
|---|---|---|
| 1화 | 90~100 (결과 113) | S#1은 표본대로 12컷. 분할 컷을 더 늘리지 않으려고 초과 허용(2026-10-10) |
| 2화 | 80~90 (결과 90) | S#1 몽타주만 코미디 데포르메 허용 |
| 3화 | 130~150 | S#1~15 약 60~70, S#16~34 약 70~85(본선 무대). 2026-10-10 분량 비례로 상향(3화 대본 43분 = 1화의 1.7배) |

- **원작 대사·내레이션은 빠짐없이 글자 그대로.** 말줄임표(…), 물음표, 사투리, 띄어쓰기도 그대로 쓴다. 연기 메모 괄호 `(반 박자 쉬고)`는 대사 칸에 넣지 않고 화면·연출 칸에 표정·손으로 옮긴다.
- **컷당 말풍선은 최대 3개, 두 화자까지.** 짧은 주고받기만 한 컷에 묶는다. 40자가 넘는 대사는 혼자 쓴다. 예외는 멀어지는 인물 위로 대화가 작아지는 여운 컷처럼 연출 이유가 있을 때만 쓴다. 그때는 화면·연출 칸에 이유를 적는다.
- **소리 색 컷은 말풍선 없이 단독으로 쓴다.** 은주의 귀가 열리는 순간이나 음악 컷이 그렇다. 효과음 글자는 넣어도 된다.
- 장면 문법: 설정샷 → 인물 → 대사 교차 → 무음 리액션 → 인서트 → 여운. 다만 장면마다 설정샷을 새로 두지 않는다. 장소가 바뀔 때만 둔다(연속 씬은 생략).
- 무음 컷은 장면당 1~3개. 리듬은 짧은 컷(500~800) 3~5개 → 긴 컷(1200~1800)으로 터뜨린다.

## 3. 형식 (킷이 읽는 형식, 엄격)

- 화 제목: `### 1화. 귀신과 깡통`, `### 2화. 버려진 소리`, `### 3화. 깡통 바이올린`
- 장면 소제목: `#### 장면: S1 갈대섬 작은 산 중턱 (새벽, 1987년 4월)`. 대본 S# 번호와 장소·시간을 대본 씬 머리 그대로 쓴다. 몽타주·회상도 같은 방식이다.
- 필요하면 소제목 아래 한 줄 `연출 메모: …`
- 표 헤더는 정확히 `| 컷 | 크기 | 샷·앵글·인물 | 화면·연출 | 대사·내레이션·SFX |`, 구분 줄 `|---|---|---|---|---|`
- **컷**: `화-세자리`(1-001부터 화마다 1씩). 각 화의 첫 컷 대사 칸에 `제목: N화 화제목`
- **크기**: `800×높이`. 높이는 360~1800, 40 단위. 기본 1000, 와이드 500~700, 긴 컷 1400~1800
- **샷·앵글·인물**: `샷 · 앵글 · 인물(위치)`. 샷은 ECU/CU/BS/MS/FS/LS/ELS/INS/TXT. 앵글은 아이레벨/로우/하이/부감/앙각/POV(누구 시점)/측면/뒷모습/오버숄더(누구 너머). 위치는 좌·중·우·전경·후경. 인물 이름은 대본 이름표(은주, 동민, 만석, 곽 영감, 선영, 최 계장, 태준, 미자, 덕수, 순례 할머니, 봉구, 영란, 경호, 경민, 순이, 석이)와 단역 역할명(갈고리 아주머니, 미자 엄마, 섬사람들…)을 쓴다. 엄마 한미숙은 `엄마(손)`·`엄마(뒷모습)`처럼 쓴다.
- **화면·연출**: 2~4문장. 자세·손 위치·표정(눈썹·입·시선 방향)·소품·빛의 방향·말풍선 위치를 쓴다. 대본의 카메라 의도와 연기 메모를 여기로 옮긴다. 소리 색 컷이면 `연청 빛 동심원`처럼 색 이름과 무엇에서 퍼지는지 쓴다. "분위기 있게" 같은 추상어는 쓰지 않는다.
- **대사·내레이션·SFX**: ` / `로 구분한다.
  - 대사 `은주: …`. 화면 밖 목소리는 `사회자(E): …`, 전화·라디오·확성기는 `라디오(F): …`처럼 대본 표기를 이름 뒤에 붙인다.
  - 내레이션(어른 은주 `은주 (N)`)은 `내레이션(어른 은주): …`
  - 효과음 `SFX: 와르르`, 작은 소리 `SFX(작게): 킥킥`, 소리 색 `SFX(연청 #9DB7C9): 쿨럭`. 소리 색 이름과 HEX는 style_guide 2절 표를 따른다(동그리 금빛 #F5C04A, 뚱보 주황 #E8944A, 꽥꽥이 청록 #4FB3A9, 뼈다귀 북 빨강 #D9534A, 소리굽쇠 은빛 흰색 #E9EEF5, 라디오 허밍 연보라 #B9A7D9, 은주의 귀 연청 #9DB7C9, 진짜 바이올린 청색 #5B8DEF, 만석의 클라리넷 와인색 #9C4A6B)
  - 음악(대본 `M:`)은 `SFX(금빛 #F5C04A): (동그리 선율)`처럼 괄호 안에 소리를 설명한다. 실제 곡의 가사·악보는 쓰지 않는다.
  - 자막·제목·공문·신문·쪽지 글자: `자막: 1987년 4월`, `제목: …`, `고지문: …`, `손글씨: …`
  - 대사가 없으면 `(무음)`
- **표 칸 안에 `|` 문자 금지, 줄바꿈 금지.** 대본 화자 지시문은 내레이션으로 옮기지 않는다.

## 4. 소리 색 (이 작품의 시각 장치)

- `scene_index.md`의 '소리 색 순간'에 적힌 컷에서만 쓴다. 대본 카메라 의도에 '귀로'·'그 소리만'이 있는 컷과 `M:` 음악 컷이 그 경우다. 그 밖에는 쓰지 않는다. 남발하면 장치가 죽는다.
- 조롱 웃음처럼 은주가 상처받는 소리(2화 S#19 객석 웃음 등)는 색을 주지 않는다. 채도만 낮춰 '색이 빠지는' 쪽으로 쓴다.
- 3화 본선(S#19~27)에서는 '새벽'부터 악기가 하나씩 더해질 때마다 색이 하나씩 늘어난다. '밤'에서 처음으로 화면 전체가 색으로 찬다. 에필로그 이중주(S#34)는 규칙 밖(자연색)이다.
- 은주의 웃음: 열세 살 은주가 활짝 웃는 것은 3화 S#27이 처음이자 유일하다. 그 전에는 '입꼬리만'. 어른 은주는 S#34에서 다시 활짝 웃는다.

## 5. 컷 사양 (GPT 프롬프트 재료, 콘티와 1:1)

콘티 md와 함께 컷마다 한 줄 JSON을 쓴다. 파일은 `storyboard/source/cut_spec_ep<N>.jsonl`이다. `tools/cut_prompts.py`가 이 사양에 그림체·씬 프리셋·인물 고정 문구·의상·소품 시트·배경 배치를 합쳐 GPT용 컷 프롬프트를 만든다. 그래서 사양에는 **그 컷에만 있는 것**만 쓴다.

```
{"id": "1-003", "scene": "1-1", "chars": ["eunju"], "extras": [], "set": "small_hill_slope", "spot": "slope_wide", "props": [], "sound": "은주의 귀", "outfit": {}, "cut_en": "..."}
```

| 필드 | 규칙 |
|---|---|
| `id` | 콘티 컷 번호 |
| `scene` | `화-S#`(예: `1-1`). 장면 소제목의 S#와 같다 |
| `chars` | **화면에 보이는** 인물 id만: eunju, dongmin, manseok, kwak, seonyoung, choi, taejun, mija, deoksu, sunrye, bonggu, yeongran, gyeongho, gyeongmin, suni, seoki. 목소리만 나오면 넣지 않는다 |
| `extras` | 단역 고정 문구 이름(style_guide 6절 '단역 고정 문구')만: 갈고리 아주머니, 미자 엄마, 집하장 아저씨, 전당포 주인, 과장(구청), 사회자, 엄마 한미숙(회상). 그 밖의 군중은 cut_en에 묘사 |
| `set` | `scene_index.md`의 그 씬 배경 id. 검은 화면·글자만 있는 컷은 `null` |
| `spot` | 그 배경의 카메라 자리 id(선택). 구도가 맞을 때만 |
| `props` | 화면에 **보이는** 소품 키. 그 씬에 맞는 상태 키(`dongguri__s2_thrown` 등)를 쓴다. 입고 있는 옷·장갑·장화·머리끈은 인물 문구에 이미 있으니 넣지 않는다(그 물건 인서트 컷이면 넣는다) |
| `sound` | 소리 색 컷이면 style.json 소리 이름 일부: `동그리`, `뚱보`, `꽥꽥이`, `뼈다귀 북`, `소리굽쇠`, `라디오 허밍`, `은주의 귀`, `태준·다솜중 바이올린`, `만석의 클라리넷`. 아니면 `null`. 본선 '밤'처럼 여러 색이면 cut_en에 색을 쓰고 대표 하나만 |
| `outfit` | 그 컷에서 의상이 씬 의상과 다를 때만 `{"eunju": "영어 의상"}` |
| `char_text` | (선택) 회상·에필로그처럼 나이·모습이 고정 문구와 다를 때 그 인물의 고정 문구를 통째로 바꿀 영어 외형. 예: 1970년대 젊은 만석(작업모 없음) `{"manseok": "Manseok in his mid-20s, ..."}` |
| `desaturate` | (선택) 기본 true. 소리 색 컷인데 화면 채도를 낮추지 않을 때(리허설, 에필로그 등 scene_index가 그렇게 정한 곳) `false` |
| `set2` | (선택) 가로 분할 컷에서 다른 칸의 배경 id |
| `pendant` | (선택) 은주의 소리굽쇠 목걸이. 기본 `true`. 2화 S#25에서 상자에 넣은 뒤부터 3화 S#3에서 만석이 다시 걸어 주기 전까지 `false`(빈 목). 옷 속에 숨은 컷은 `"hidden"`. 도구가 고정 문구의 목걸이 구절을 이 값으로 바꾼다 |
| `colors` | (선택) 한 컷에 소리 색이 둘 이상일 때 HEX 목록(3화 본선 누적, '밤'). 있으면 [SOUND]가 이 색들로 만들어진다. `sound`는 대표 하나로 남긴다 |
| `sound_style` | (선택) `"dots"`: 소리 색이 화면으로 번지지 않고 악기 둘레 작은 점으로만(리허설 등) |
- 회상 장소가 같은 씬 프리셋에 들어 있는 씬(3-3 극장, 3-12 1950년대 판자촌, 3-21 라디오 수리점): 도구는 `set`이 `fb_*`이거나 cut_en이 `flashback`으로 시작하면 회상 장소 문장만, 분할 칸에 회상이 있으면 둘 다, 아니면 현재 장소만 붙인다.
- 쓰레기 산의 아이들(은주·동민·미자·덕수·섬 아이)은 씬 의상에 목장갑·장화가 없으면 `outfit`으로 넣는다. 반대로 집 안·공방 실내·연습실에서는 장화를 빼고, 악기를 켜는 손은 맨손이다(장갑은 주머니에). 씬 의상 영어에 목장갑·장화가 붙어 있으므로 `outfit`으로 덮는다.
| `cut_en` | 영어 40~90단어. 순서: 샷·앵글(style_guide 4절 문구) → 구도와 위치(left/right/foreground) → 동작 → 표정·손(연기 메모) → 빛의 방향. 글자가 있는 종이·신문·간판은 `unreadable blank columns suggesting text`로 쓴다. 분할 컷은 `panel split horizontally into two frames. Top: … Bottom: …`. 인물 외형·의상·그림체·배경 배치는 반복하지 않는다(자동으로 붙는다) |

## 6. 연속성

- 의상은 씬 프리셋(`scene_index.md` 인물·의상)을 따른다. 컷 안에서 바뀌면(예: 1-11 목장갑 벗음) 화면·연출에 쓰고 사양 `outfit`으로 덮는다.
- 소품 상태는 씬에 맞는 상태 키를 쓴다(동그리: 처음 → 던져짐 → 포크 교체 → 버려짐 → 복원).
- 시간·빛은 씬 프리셋의 빛 방향을 따른다. 곽 영감은 허리가 꼿꼿하고 만석은 등이 약간 굽었다. 만석은 늘 작업모를 쓴다.
- 호칭: 대사의 '아빠'와 지문의 '만석'을 지킨다. 은주는 태준에게 반말, 미자에게 존댓말을 쓴다.

## 7. 넘지 않는 선 (완화 불가)

- 아동 인물은 어떤 컷에서도 성적·선정적으로 그리지 않는다. 몸 라인 강조, 노출 의상, 꾸민 포즈는 없다. 아이들은 제 나이의 평범한 아이로 그린다. 이 작품은 성인 트랙(webtoon_adult)을 쓰지 않는다.
- 12세 이상: 부상·피·질병·죽음은 직접 그리지 않는다. 위험 행동은 어른이 막거나 결과만 보여 준다. 쓰레기 산에서 아이들은 목장갑과 장화를 쓰고, 유리·주삿바늘을 맨손으로 만지는 그림은 없다. 자연 발화 연기는 원경에만 둔다.
- 만석이 동그리를 던지는 컷(2화 S#10)에서는 물건만 보이고, 사람 쪽으로 향하지 않는다. 팔이 다 올라가기 전에 은주 얼굴로 넘긴다.
- 엄마 한미숙은 얼굴을 보이지 않는다(손·뒷모습·빛).
- 실존 인물을 닮게 그리지 않는다. 실제 기관·브랜드 로고, 실제 화폐 도안, 올림픽 공식 마스코트·엠블럼은 없다. 간판·공장명·신문명은 가공(「한강신보」)이다.
- 새 사건·설정을 더하지 않는다. 원작에 없는 대사는 짧은 리액션("…", 숨소리) 정도만 최소로 쓴다.

## 8. 작업 나눔과 점검
