## 1-051 (1화. 귀신과 깡통 / S6 강변교회 지하 공부방 (토요일 저녁))
- 샷·앵글·인물: MS · 아이레벨 · 선영(중)
- 샷 길이: 5.0초 @24fps (120프레임)
- 카메라: static hold, subtle parallax
- 레이어: BG / 인물 / FX / 레터링
- 연기·화면: 칠판 앞. 안경을 고쳐 쓰고 치마를 턴 선영이 꾸벅 인사한다. 두 번째 말은 고쳐 말하느라 중간이 끊긴다(말풍선 안 말줄임).
- 대사(립싱크·VO):
  - [dialogue] 선영: 아, 안녕하세요. 백선영이에요.
  - [dialogue] 선영: 오늘부터 국어랑 산수를… 가르쳐요. 가르칩니다.
- 인물 시트:
- 백선영: 23세 성인, 162cm, 마른 체형, 7등신, 단발(#2B2420), 피부 #F1D3BB, 볼륨 있는 반곱슬 파마 단발에 부풀린 앞머리, 크고 동그란 금테 안경, 동그란 얼굴, 소품: 안경, 의상(장면별): 구겨진 흰 셔츠·카디건·긴 플레어스커트(#F2EFE8) / 검은 연주복(무대)(#1E1E22) / 베이지 더플코트·목도리(늦가을~겨울)(#CDB894) / 단정한 감색 정장(2003, 음악 교사)(#2A3350) / 구겨진 흰 반소매 블라우스·긴 플레어스커트(여름)(#F2EFE8), 연기: 아이들보다 더 허둥대지만 결정적일 때 단단하다
- 금지·수위:
- 실존 인물·유명인과 닮은 얼굴 금지 (모든 얼굴은 창작)
- 실제 기관·브랜드 로고·실제 화폐 도안·올림픽 공식 마스코트와 엠블럼 금지. 간판·공장명은 가공
- 아동 인물은 어떤 컷에서도 성적·선정적으로 그리지 않는다: 몸 라인 강조·노출 의상·꾸민 포즈 없음, 아이들은 제 나이의 평범한 아이로
- 12세 이상: 부상·피·질병·죽음을 직접 그리지 않는다. 위험 행동은 어른이 막거나 결과만
- 쓰레기 산에서 아이들은 목장갑·장화 착용, 유리·주삿바늘 같은 위험 폐기물을 맨손으로 만지는 그림 없음
- 엄마(한미숙)는 얼굴을 보이지 않는다(손·뒷모습·빛)
- 이미지 안에 말풍선·글자 넣지 말 것 (레터링은 후공정)
