## 1-086 (1화. 귀신과 깡통 / S11 작은 산 꼭대기 (저녁, 나흘째))
- 샷·앵글·인물: MS · 로우 · 동민(전경), 곽 영감(우), 은주(좌)
- 샷 길이: 4.1초 @24fps (98프레임)
- 카메라: static hold, subtle parallax
- 레이어: BG / 인물 / FX / 레터링
- 연기·화면: 전경 아래쪽, 사탕을 입에서 뺀 동민이 눈이 동그래져 누나 얼굴을 올려다본다(누나한테서 처음 듣는 말). 영감이 대꾸 없이 깡통을 쌌던 천을 개어 은주 손에 쥐여 주며 무뚝뚝하게 말한다.
- 대사(립싱크·VO):
  - [dialogue] 곽 영감: 갖고 싶으면 매일 와서 켜. 안 켜면 도로 가져간다.
- 인물 시트:
- 하은주: 13세, 140cm, 작고 가는 체형, 5.5등신, 긴 머리(#2A211C), 피부 #E2B48E, 갸름하고 작은 얼굴, 크고 긴 아몬드형 눈, 짙고 곧은 눈썹, 앞머리 없이 이마를 드러내고 잔머리가 흘러내림, 코와 볼에 옅은 주근깨, 그을린 볼, 소품: 목걸이, 의상(장면별): 큰 남색 점퍼·해진 바지·목장갑(#2E3A5C) / 흰 블라우스·감색 치마(학교)(#F1EEE6) / 빌린 흰 원피스(무대)(#FAFAF7) / 남색 점퍼·회색 손뜨개 목도리·목장갑(겨울)(#2E3A5C) / 남색 점퍼·회색 손뜨개 목도리·손끝 자른 목장갑(겨울)(#2E3A5C) / 빛바랜 하늘색 반소매 셔츠·해진 바지(여름)(#A9C6D9) / 짙은 남색 연주 드레스(2003, 어른)(#24304F), 연기: 큰 표정 대신 귀와 손. 감동은 숨 멈춤으로. 마지막 무대에서 처음 활짝 웃는다. 목에 은색 소리굽쇠 목걸이
- 하동민: 9세, 125cm, 작고 가는 체형, 5등신, 아주 짧게 민 머리(#2A211C), 피부 #E8BC96, 동그란 얼굴, 아주 짧은 까까머리, 윗줄 왼쪽 앞니 하나 빠짐, 큰 귀, 오른쪽 무릎 반창고, 의상(장면별): 물려받은 큰 운동복(#3F7A55) / 물려받은 누빈 갈색 점퍼·털모자(겨울)(#7A5A3C) / 초록 반소매 체육복 티·반바지(여름)(#3F7A55) / 흰 반소매 남방·감색 반바지(제일 좋은 옷)(#F4F2EC) / 흰 반소매 남방·감색 반바지·빨간 손수건(본선)(#F4F2EC) / 검은 티셔츠·청바지(2003, 어른)(#1E1E22), 연기: 몸 전체로 말한다. 슬픈 장면에서 엉뚱한 한마디
- 곽태복: 68세 성인, 160cm, 다부진 체형, 6.5등신, 아주 짧게 민 머리(#E8E6E1), 피부 #C69A76, 각진 턱, 짧은 흰 스포츠머리, 굵고 짧은 흰 눈썹, 깊은 이마 주름, 두꺼운 팔뚝, 허리를 꼿꼿이 세움, 소품: 안경, 의상(장면별): 톱밥 묻은 캔버스 앞치마·팔토시(#8A7556) / 앞치마 위 회색 털조끼·털모자(겨울)(#6E6A65) / 깨끗한 갈색 카디건(2003)(#8A6A4A) / 앞치마·반소매 작업 셔츠(여름)(#8A7556) / 다린 흰 반소매 셔츠·회색 바지(본선)(#F2F0EA), 연기: 표정 변화 거의 없음. 감정은 작업하는 손의 속도로. 웃음은 두 번뿐
- 금지·수위:
- 실존 인물·유명인과 닮은 얼굴 금지 (모든 얼굴은 창작)
- 실제 기관·브랜드 로고·실제 화폐 도안·올림픽 공식 마스코트와 엠블럼 금지. 간판·공장명은 가공
- 아동 인물은 어떤 컷에서도 성적·선정적으로 그리지 않는다: 몸 라인 강조·노출 의상·꾸민 포즈 없음, 아이들은 제 나이의 평범한 아이로
- 12세 이상: 부상·피·질병·죽음을 직접 그리지 않는다. 위험 행동은 어른이 막거나 결과만
- 쓰레기 산에서 아이들은 목장갑·장화 착용, 유리·주삿바늘 같은 위험 폐기물을 맨손으로 만지는 그림 없음
- 엄마(한미숙)는 얼굴을 보이지 않는다(손·뒷모습·빛)
- 이미지 안에 말풍선·글자 넣지 말 것 (레터링은 후공정)
