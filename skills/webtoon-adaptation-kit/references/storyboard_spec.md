# 웹툰 콘티 작성 규격

## 목표
소설 문단 하나를 컷 하나로 옮기면 "웹소설에 삽화를 붙인" 결과가 된다. 웹툰 콘티는 장면을 동작·감정·시선 단위로 잘게 쪼갠다. 경험치: 원작 문단 1개당 3~6컷, 한 회차(장) 30~70컷.

## 컷 쪼개기 원칙
1. **한 컷 = 한 동작 또는 한 감정 또는 한 정보.** 대사는 컷당 최대 2개(같은 화자 연속이면 2개, 다른 화자면 원칙적으로 컷을 나눔).
2. **장면 문법:** 설정샷(어디·언제) → 인물 등장(MS/FS) → 대사 교차(숏/리버스숏, 화자 쪽 BS·CU) → 리액션 컷(대사 없는 표정 CU) → 디테일 인서트(손·소품·시계·문손잡이 등 ECU) → 여운/전환 컷(빈 공간, 하늘, 텍스트만).
3. **대사 없는 컷을 적극적으로 쓴다:** 눈 깜빡임, 침 삼킴, 손 멈춤, 시선 이동, 침묵의 2인 숏. 웹툰의 리듬은 무음 컷에서 나온다.
4. **세로 스크롤 리듬:** 짧은 컷(높이 360~600) 3~5개를 빠르게 이어 긴장 → 긴 컷(1200~1800)으로 터뜨림. 높이를 다양하게. 가로로 넓은 분할 컷(2~3분할)도 섞는다.
5. **블랙코미디 타이밍:** 웃음 포인트는 "진지한 컷 → 한 박자 쉬는 무음 리액션 컷 → 반전 대사" 순으로 배치.
6. **원작 대사·내레이션은 빠짐없이 원문 그대로** 넣는다(표현 바꾸지 말 것). 원작에 없는 대사는 짧은 리액션("…", "네?", 숨소리, 사투리 감탄 정도)만 최소한으로 추가 가능. 새 사건·설정 추가 금지.
7. 화면 설명은 구체적으로: 인물의 정확한 자세·손 위치·표정(눈썹·입·시선 방향), 배경 소품, 조명 방향, 효과선 종류. "분위기 있게" 같은 추상어 금지.

## 분량
원작 문단 1개당 3~6컷. 대사가 많은 장면은 더 촘촘히. 장이 길면 여러 작업자(서브에이전트)에게 장면 범위를 나눠 맡기고, 각자 임시 번호(예: 2-201부터)로 쓴 뒤 합치면서 재번호한다.

## 출력 형식 (엄격)
- 파일 하나에 마크다운으로 작성. 장 제목은 `### 2장. 불륜의 기술 (전반)` 처럼 `### `.
- 장면마다 `#### 장면: 짧은 장면명 (장소, 시각)` 소제목을 단다.
- 필요하면 장면 소제목 아래 한 줄 `연출 메모: …`.
- 표 헤더는 정확히 아래 5열:

| 컷 | 크기 | 샷·앵글·인물 | 화면·연출 | 대사·내레이션·SFX |
|---|---|---|---|---|

- **컷**: `장번호-세자리번호` (예: `2-001`). 파트 안내에서 지정한 시작 번호부터 1씩 증가. 표지는 `0-001`, 에필로그는 `E-001`.
- **크기**: `800×높이` (높이 360~1800, 40 단위 권장). 분할 컷이면 화면·연출에 "가로 2분할" 등 명시.
- **샷·앵글·인물**: `샷 · 앵글 · 인물(위치)` 형식. 
  - 샷: ECU(극단적 클로즈업) / CU / BS(바스트) / MS(허리) / FS(전신) / LS(원경) / ELS(초원경) / INS(소품 인서트) / TXT(텍스트 컷)
  - 앵글: 아이레벨 / 로우 / 하이 / 부감 / 앙각 / POV(누구 시점) / 측면 / 뒷모습 / 오버숄더(누구 너머)
  - 인물(위치): 위치는 좌·중·우·전경·후경 중 하나. 실루엣이면 `(실루엣)`. 인물 없으면 `인물 없음`. 예: `BS · 오버숄더(정만 너머) · 인턴(중), 정만(좌·전경)`
  - 인물 이름은 data/characters.json의 name을 그대로 쓰고, 그 외는 역할명(구급대원, 검사 등). 위치 자리에 신체 부위를 쓰지 말고 화면·연출 칸에 적는다(썸네일 자동 배치가 위치를 읽는다).
- **화면·연출**: 2~4문장. 자세·표정·소품·조명·효과선·말풍선 위치.
- **대사·내레이션·SFX**: ` / ` 로 구분. 형식 `화자: 내용`. 내레이션은 `내레이션:` 또는 `내레이션(밤):`, 효과음은 `SFX:` (크기·색 지시는 괄호 `SFX(작게):`), 생각은 `무진(생각):`, 속삭임은 `서희(속삭임):`. 없으면 `(무음)`.
- **표 칸 안에 `|` 문자 금지.** 줄바꿈 금지(한 행 = 한 줄).

## 수위·안전 규칙 (반드시)
- 정사 장면: 실루엣·역광·신체 일부 클로즈업(손, 반지, 입술, 어깨, 목선)·떨어진 옷가지·소품·효과음으로만 암시. 성기·가슴 노출, 행위의 직접 묘사 금지. 자세는 원작 수준(벽에 기댐, 다리가 허리를 감음 등)까지만, 실루엣으로.
- 폭력: 타격 순간은 집중선·실루엣·효과음. 상처·출혈·두개골 손상 그리지 않음. 수술 장면도 수술포·조명·손·모니터로 처리, 절개 부위 묘사 금지.
- 투신: 뛰어내리는 순간 그리지 않음. 남겨진 구두·유서 → 물속 헤엄으로 바로 넘어감.
- 실존 인물·실제 병원/방송사 로고 금지. 인물·병원명은 원작의 가명 그대로.
- 원작의 '○○가 말했다' 같은 화자 지시문은 말풍선이 화자를 보여 주므로 내레이션으로 옮기지 않아도 된다. 콘티 개요에 이 원칙을 적어 둔다.

## 합친 뒤 검수 (별도 작업자에게)
원작 따옴표 대사 전수 대조, 원작에 없는 사건·설정, 수위 위반, 번호 연속·5열 형식, 의상·소품·시간·장소 연속성을 확인한다. 실제로 이 단계에서 '아파트↔빌라', '피부과(전문의 설정 추가)', '보름달↔반달' 같은 오류가 잡혔다.
