# 웹툰 콘티 작성 규격

작품마다 이 규격을 바탕으로 `storyboard/SPEC.md`를 만든다. 작품 SPEC과 이 문서가 다르면 작품 SPEC이 우선이다. 작품 SPEC에 넣을 것은 다음과 같다.
- 작품 수위 줄
- 인물 이름 목록
- 회차별 특별 지시
- 반복 장치 구도
- 읽을 문서 목록

## 목표

소설 문단 하나를 컷 하나로 옮기면 "웹소설에 삽화를 붙인" 결과가 된다. 웹툰 콘티는 장면을 동작·감정·시선 단위로 잘게 쪼갠다.

**분량**
- 표준: 원작 문단 1개당 3~6컷, 한 회차 30~70컷.
- 세분화판(성인 드라마·블랙코미디에서 검증): 회차당 75~95컷, 대본 S# 하나가 4~10컷이다.
  - 다섯 명 대조나 클라이맥스처럼 작품의 핵심 장면은 10컷을 넘겨도 된다. 넘기면 작성자 보고에 이유를 적는다.

## 작성자에게 먼저 읽힐 것 (회차를 맡길 때 프롬프트에 명시)

1. 작품 SPEC(전부)
2. 형식·밀도 견본: 이미 승인된 회차의 앞 40~70행, 그리고 관능 장면 한 절
3. 그 회차의 소설과 대본(전부). 대본 끝 '변경 기록' 포함
4. 캐릭터 바이블: 외형 고정값·LOCK, 회차별 의상표, 몸짓. 배경 인물 포함
5. 배경 설정서: 장소 목록, 이 회차 장소 절만(프롬프트 하위 절 제외). 관능 장면 장소는 수위 장치 절이 필수
6. 소품 LOCK, 스타일 LOCK

## 컷 쪼개기 원칙

1. **한 컷 = 한 동작 또는 한 감정 또는 한 정보.**
   - 대사는 컷당 최대 2개다.
   - 화자가 다르면 원칙적으로 컷을 나눈다.
2. **장면 문법**: 설정샷(어디·언제) → 인물 등장(MS/FS) → 대사 교차(숏/리버스숏, 화자 쪽 BS·CU) → 무음 리액션 CU → 디테일 인서트(ECU) → 여운·전환 컷.
3. **대사 없는 컷을 적극적으로 쓴다**: 눈 깜빡임, 침 삼킴, 손 멈춤, 시선 이동, 침묵의 2인 숏.
4. **세로 스크롤 리듬**: 짧은 컷(360~600) 3~5개로 긴장을 쌓고, 긴 컷(1200~1800)으로 터뜨린다. 가로 2~3분할 컷도 섞는다. 회차 마지막 컷은 훅이다.
5. **블랙코미디 타이밍**: 진지한 컷 → 한 박자 무음 리액션 → 반전 대사.
6. **원작 대사와 내레이션**
   - 원작의 큰따옴표 대사는 빠짐없이 원문 그대로 넣는다.
   - 해설·내면·논평 성격의 내레이션은 원문 그대로 `내레이션:`으로 넣는다.
   - 순수한 동작·시각 묘사 문장은 내레이션으로 옮기지 않고 화면·연출 칸의 그림 지시로 바꾼다.
   - "○○가 말했다" 같은 화자 지시문은 버린다. 말풍선이 화자를 보여 준다.
   - 새로 넣을 수 있는 것은 짧은 리액션("…", "네?", 숨소리)뿐이다. 새 사건·설정은 넣지 않는다.
   - 대본과 소설이 다르면 소설 대사를 따르고, 대본 '변경 기록'을 확인한다.
7. **화면 설명은 구체적으로**: 자세, 손 위치, 표정(눈썹·입·시선), 의상(색·재질·몸 라인), 배경 소품, 조명(광원·방향·색), 효과선을 쓴다. 추상어는 쓰지 않는다.
8. **반복 장치는 같은 구도로**: 작품에서 반복되는 대사·행동은 처음 나올 때부터 같은 샷·앵글·몸짓으로 그린다. 예: "너한테만 하는 얘긴데"는 `BS · 오버숄더(여자 너머) · 도겸(중)`에 왼손 귓불, 왼쪽 입꼬리. 회상·반복 회차에서 바뀌는 것은 색 틴트와 배경 소품뿐이다. 이 구도를 작품 SPEC에 문장으로 고정해 모든 작성자에게 같은 문장을 준다.
9. **회차 경계**: 앞 회차 마지막 컷과 다음 회차 첫 컷은 같은 구도·의상·조명으로 잇는다. 다음 회차 첫 컷이 이미 있으면 그 행을 읽고 맞춘다.
10. **회상**: 화면 칸 첫머리에 `회상 톤(…)`을 적는다. 원장면 컷이 있으면 `원컷 2-023 재사용`처럼 번호를 적고 구도·의상을 맞춘다.

## 출력 형식 (엄격, 킷과 검사기가 읽는다)

- 회차 제목: `### 1화. 제목`. 표지는 `### 표지` 아래 `#### 장면: S#0 표지 (…)`와 `0-001`부터.
- **장면 소제목**: `#### 장면: S#3 장면 이름 (장소, 날짜 요일 시각)`. 대본 S# 번호를 반드시 단다.
- **연출 메모**: 장면 소제목 바로 아래 한 줄 `연출 메모: …`. 다섯 요소를 ` · `로 잇는다.
  1. 장소 ID: `장소 2(…)`. 배경 설정서 번호이며, 킷이 SET LOCK을 찾는 데 쓴다.
  2. 조명: 설정서의 해당 시각 줄을 요약한다. 광원·방향·색온도·HEX.
  3. 인물별 의상: 바이블 회차 의상표, HEX. 바이블에 없으면 '콘티 지정'이라고 쓴다.
  4. 트랙
  5. 감정 목표
  - 관능·노출·폭력 장면이면 `수위 장치: …`를, 아이가 나오는 장면이면 그 사실을 덧붙인다.
- **표 헤더**는 정확히 5열이다.

| 컷 | 크기 | 샷·앵글·인물 | 화면·연출 | 대사·내레이션·SFX |
|---|---|---|---|---|

- **컷**: `회차-세자리`(예 `2-007`). 회차마다 001부터 연속이고, 에필로그는 마지막 회차 번호를 잇는다.
- **크기**: `800×높이`. 높이는 360~1800, 40 단위다. 분할 컷이면 화면 칸에 "가로 2분할", "세로 3단", "위아래 2분할"이라고 쓴다(애니 도구가 칸 수를 읽는다).
- **샷·앵글·인물**: `샷 · 앵글 · 인물(위치), 인물(위치)`
  - 샷: ECU / CU / BS / MS / FS / LS / ELS / INS / TXT
  - 앵글: 아이레벨 / 로우 / 하이 / 부감 / 앙각 / POV(누구 시점) / 측면 / 뒷모습 / 오버숄더(누구 너머)
  - **인물은 화면에 실제로 나오는 사람만** 쓴다. POV의 주인이나 화면 밖 목소리는 쓰지 않는다. 킷이 이 칸으로 LOCK을 붙이고 아이 등장을 판정한다.
  - 이름은 data/characters.json의 name 그대로 쓰고, 그 밖은 역할명이다.
  - **여러 명은 쉼표로** 나열한다(`유진(우), 미란(우)`). `유진·미란`처럼 '·'로 묶지 않는다.
  - 위치는 좌·중·우·전경·후경이고, 실루엣이면 `(실루엣)`, 아무도 없으면 `인물 없음`이다.
- **화면·연출**: 2~4문장.
  - 트랙 2·3 컷은 맨 앞에 `[트랙2]`·`[트랙3]`을 쓴다.
  - **말풍선 위치, 효과음 글꼴, 식자 지시는 그림 지시와 다른 문장이나 다른 쉼표 구절로** 쓴다. 인계 도구가 이미지 프롬프트를 만들 때 그 구절만 뺀다. 예: "…쇄골이 빛난다. 말풍선 좌상."
  - 실제 브랜드명은 쓰지 않고 일반명으로 쓴다(검정 세단, 로고 없는 시계, 퀼팅 체인 백). 화폐는 '소품용 지폐(도안 없음)', 앱 화면은 '가상 UI'다.
- **대사·내레이션·SFX**: ` / `로 구분하고 `화자: 내용` 형식으로 쓴다.

| 종류 | 표기 |
|---|---|
| 내레이션 | `내레이션:` |
| 문자 | `문자(A→B):` |
| 생각 | `A(생각):` |
| 속삭임 | `A(속삭임):` |
| 전화 너머 | `A(전화):` |
| 화면 밖 목소리 | `A(V.O.)` |
| 동시 대사 | `다섯:` 등 |
| 효과음 | `SFX(크기, 색): 표기` |
| 대사 없음 | `(무음)` |

  - 대사·내레이션 원문 속 브랜드 단어는 원문이므로 둔다.
- **표 칸 안에 `|` 문자 금지.** 한 행은 한 줄이다.

## 수위·안전 규칙

작품의 수위 줄(G1)을 SPEC에 그대로 적는다.

**15세 기본**: 정사 장면은 실루엣·역광·신체 일부 클로즈업(손, 반지, 입술, 어깨, 목선)·떨어진 옷가지·소품·효과음으로만 암시한다. 노출과 행위 묘사는 하지 않는다.

**19세 확장**
- 허용: 몸 라인, 깊은 V넥·슬릿, 슬립·속옷, 옷이 벗겨지는 과정, 드러난 등·어깨·쇄골·허리·허벅지, 시트로 가린 나신, 실루엣과 역광의 맞닿은 몸, 손과 입술, 땀과 숨, 정사 장면 8~16컷.
- 금지: 성기, 유두 노출, 삽입·행위의 직접 묘사, 체액.
- 금지 지점은 장소별 수위 장치(커튼·시트·실루엣 광원·사물 인서트)로 컷을 넘긴다.
- 거울·유리처럼 반사가 있는 구도는 반사상이 가림 장치를 무력화하지 않게, 반사상을 어디서 자르는지까지 적는다.

**모든 등급 공통**
- **아이**: 관능 장면과 같은 컷·장면·공간에 두지 않는다. 아이가 있는 장면에는 몸 라인 강조도 하지 않는다.
- **앳돼 보이기 쉬운 성인**: 관능 장면 메모마다 '성인 체형·성숙한 표정'을 적는다.
- **폭력**: 타격 순간은 집중선·실루엣·효과음으로 처리한다. 상처·출혈은 그리지 않고, 체포는 비폭력으로 그린다.
- **투신**: 뛰어내리는 순간을 그리지 않는다.
- **실존 인물·실제 기관 로고·화폐 도안**을 그리지 않는다.

## 합친 뒤 검수

1. **자동 검사**: `python3 check_board.py <프로젝트> <회차>`(스튜디오) 또는 `--board 콘티.md --novel 소설.md`.
   - 형식 문제 0, 원작 대사 누락 0이어야 통과다.
   - `--list`로 대사 칸에 없는 내레이션 문장을 보고, 해설·내면 문장이 빠졌으면 넣는다.
2. **별도 서브에이전트 검수**(작성자와 다른 에이전트)
   - 수위·안전: 전 회차, 컷 단위 판정. [필수]/[권장]으로 나누고, 고칠 문장을 제안하게 한다.
   - 연속성: 회차를 반으로 나눠 맡긴다. 의상 HEX, 소품, 조명·시각, 날짜·요일, 회차 경계, 회상 원컷 대조, 대표 색 규칙을 본다.
   - 실제로 잡힌 오류 예: '아파트↔빌라', '보름달↔반달', 거울 반사로 인한 노출, 인물을 '·'로 나열.
3. **반영**: 지적은 컷 번호 기준 문자열 치환 스크립트로 반영하고, 반영 후 자동 검사를 다시 돌린다.
